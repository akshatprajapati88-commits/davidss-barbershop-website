DAVID'S BARBERSHOP — WEBSITE FILES
==================================

WHAT IS INCLUDED
----------------
index.html   The complete website. HTML, CSS and JavaScript are all inside
             this one file, so there is nothing to install and nothing to build.

HOW TO LOOK AT IT
-----------------
Double-click index.html — it opens in any web browser and works offline.
(An internet connection is needed for the 3D barber pole animation, the fonts
and the Google Maps button, which load from free public services.)

HOW TO PUT IT ON THE INTERNET (FREE)
------------------------------------
Option 1 — GitHub Pages
  1. Create a free account at github.com
  2. Create a new repository (for example: davids-barbershop-website), Public
  3. Click "uploading an existing file" and upload index.html, then Commit
  4. Go to Settings > Pages, set Source to "Deploy from a branch",
     Branch = main, Folder = / (root), then Save
  5. After a minute the site is live at
     https://YOUR-USERNAME.github.io/davids-barbershop-website/

Option 2 — any web host
  Upload index.html to the top folder of any hosting account. That is the
  whole installation.

CUSTOM WEB ADDRESS (OPTIONAL)
-----------------------------
Buy a domain (for example davidsbarbershopbrooklyn.com) and point it at your
hosting. On GitHub Pages you can do this under Settings > Pages > Custom domain.

EDITING THE CONTENT
-------------------
Open index.html in any text editor (Notepad, TextEdit, VS Code). The business
details are written in plain text:
  - Phone number: search for 718-643-3930
  - Address: search for 194 Court St
  - Opening hours: search for SCHEDULE near the bottom of the file
Colours and fonts are at the top of the file inside the <style> block.

WHAT IS NOT INCLUDED
--------------------
The site was written using only the public Google Business information for the
shop: name, address, phone number, opening hours, services and three customer
review quotes. There are no prices and no photographs.
